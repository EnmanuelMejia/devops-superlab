## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

Use GitHub's [private vulnerability reporting](../../security/advisories/new) on this repository, or contact the maintainer via the profile contact channels.

We aim to acknowledge reports within 72 hours and will work with you on a fix and coordinated disclosure timeline.

## Scope

This policy covers the code in this repository. Third-party dependencies are handled via Dependabot security updates.
